# 桌面 AI 悬浮助手

把 WorkBuddy / 豆包 / DSH 变成桌面上的一个常驻悬浮球。**装好即用，不用登录，不用配密钥。**

点悬浮球展开，聊天内容和输入框是两个独立窗口；输入框平时透明地贴在角落、点击穿透，双击才醒；空输入连按两次 Enter 收回小球，AI 继续在后台跑。

---

## 为什么不用登录

因为**不新建会话**。

悬浮层接管的是你已经登录、正在用的那个客户端窗口——读它渲染出来的对话，往它的输入框里写。原来的登录态、原来的会话、原来的上下文，一个都不动。

这也是唯一能做到"装完直接能用"的方式：任何"新起一个引擎"的方案，都必然要再登录一次。

---

## 跑起来

```bash
python run.py
```

或者双击 `安装并启动.bat`（自动装依赖，无控制台窗口）。

首次运行会在屏幕左侧出现一个圆形悬浮球。右键 → 目标软件 切换客户端。

---

## 三个客户端怎么接的

| 客户端 | 接法 | 需要准备什么 |
|---|---|---|
| **WorkBuddy** | 接管运行中的窗口 | 无 |
| **豆包** | 接管运行中的窗口（复用豆包自己的悬浮球入口） | 无 |
| **DSH** | 接管运行中的窗口 | 无 |

统一走 `overlay/windowbridge.py`：

- **读**：UIA `TextPattern` 取整页文本，比对前后差异得到新回复，实时流进展示窗
- **写**：切前台 → 点输入区 → 粘贴 → **写后校验** → 回车
- **校验**：粘贴后重新读文本，确认这句话真的落进了输入框；没落进去就 `Ctrl+Z` 撤销并报错，绝不误发
- **安全阀**：目标窗口不在前台就拒绝操作，不会把点击打到别的程序上

## 作为技能安装

仓库根目录有 `SKILL.md`，可以直接对 WorkBuddy 说：

> 帮我安装 GitHub 上的 LastTrainKing/desktop-ai-overlay

装完它会知道怎么启动、怎么排错。豆包同理（把仓库放到它的技能目录）。

## 操作

| 操作 | 效果 |
|---|---|
| 单击悬浮球 | 展开 / 收起 |
| 拖动悬浮球 | 换位置（自动记忆） |
| 右键悬浮球 | 切换客户端 / 连接状态 / 重置位置 / 清空对话 / 退出 |
| 双击输入框 | 唤醒并获得焦点 |
| Enter | 发送（Shift+Enter 换行） |
| 空输入连按两次 Enter | 收起 |
| Esc | 输入框回到透明待命 |
| `Ctrl+Alt+Space` | 全局唤起 / 收起 |
| `Ctrl+Alt+H` | 全局收起 |

## 结构

```
desktop-ai-overlay/
├─ SKILL.md                技能清单（给智能体看的安装/启动说明）
├─ 安装并启动.bat           一键装依赖并启动
├─ run.py                  入口
├─ overlay/
│  ├─ windowbridge.py      窗口接管：读文本 / 写输入 / 写后校验
│  ├─ adapters.py          统一适配器 + 三通道装配
│  ├─ core.py              状态持久化 + 全局钩子 + 穿透控制
│  ├─ ui.py                悬浮球 / 展示窗 / 输入框 / 连接状态
│  ├─ credbridge.py        读取运行中客户端的启动环境（高级用途）
│  └─ app.py               控制器
├─ docs/可行性调研报告.md
└─ tests/                  端到端验证脚本
```

状态文件：`%APPDATA%\DesktopAIOverlay\state.json`

## 已验证 / 边界

**已验证（真机）**
- 三窗口分离、独立几何、位置记忆、多屏回退
- 输入框透明穿透 + 全局双击唤醒 + 自动聚焦（真实 `SendInput` 注入）
- 空输入双击 Enter 收起（真实按键注入）
- 收起后会话存活、展开还原消息与窗口
- WorkBuddy 对话文本读取（3861 字符实测）
- 豆包对话文本读取（870 字符实测）
- 非前台时拒绝发送，不误点

**边界**
- 只支持 Windows
- 读的是窗口里已渲染的文本，图片/卡片只能拿到占位符
- 客户端大改版可能挪动输入区，改 `windowbridge.py` 的 `PROFILES` 即可
- 发送会占用客户端前台，别在全屏游戏时用
